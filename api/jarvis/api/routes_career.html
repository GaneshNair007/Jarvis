Module jarvis.api.routes_career

Career-Ops REST API Routes (PWR-328 to PWR-337).

Exposes endpoints for job scanning, ATS resume generation, cover letter creation, company research, contact discovery, application tracking, interview prep, and offer negotiation.

def update_application_status(application_id: str,
request: UpdateStatusRequest)
Expand source code 
@router.patch("/applications/{application_id}/status")
def update_application_status(application_id: str, request: UpdateStatusRequest):
    """Updates the status of a tracked application."""
    updated = career_powers.service.update_application_status(
        application_id=application_id, new_status=request.status, note=request.note
    )
    if not updated:
        raise HTTPException(status_code=404, detail="Application not found")
    return updated.model_dump()
