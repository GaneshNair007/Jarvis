# GitHub Achievement Badges: Quick-Start Guide

Follow these quick steps to trigger your GitHub achievements:

## 1. ⚡ Quickdraw (< 1 Minute)
1. Open an issue on GitHub: `https://github.com/GaneshNair007/Jarvis/issues/new`
2. Title: `Test quickdraw`
3. Click **Submit new issue**, then immediately scroll down and click **Close issue**.

## 2. 🦈 Pull Shark (2 Minutes)
1. Make a small commit on a branch (e.g. `feature/docs`).
2. Open a Pull Request and merge it into `main`.
3. Merging 2 PRs unlocks Bronze Pull Shark; 16 unlocks Silver.

## 3. 👯 Pair Extraordinaire (2 Minutes)
Commit with a co-author trailer and merge via PR:
```bash
git commit -m "feat(collab): add pair workflow

Co-authored-by: Octocat <octocat@github.com>"
```
Merge the PR into `main` to unlock!

## 4. 🧠 Galaxy Brain (3 Minutes)
1. In repository Settings, enable **Discussions**.
2. Create a discussion in the **Q&A** category.
3. Answer the discussion and click **Mark as answer**.
